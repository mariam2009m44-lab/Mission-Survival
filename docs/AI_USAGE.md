# AI usage disclosure

AI assistance was used to help draft and refactor application code, interface text, tests and documentation.

Scientific dataset names, coverage dates, release numbers and limitations are tied to official NASA, NASA PDS and Canadian Space Agency sources listed in docs/RESEARCH.md and data/mission-science.json.

Game mechanics are original educational abstractions. They are not operational spacecraft procedures, astronaut medical guidance or measured mission telemetry.

No NASA logo, flag, mission insignia or other NASA branding was generated or modified. No AI-generated scientific data is presented as an observation.

## NOVA assistant
NOVA is a project-authored bilingual retrieval assistant. It selects from a curated set of reviewed lunar-science explanations and returns official source links. It is not a generative AI model, is not NASA-GPT, and is not endorsed or operated by NASA. It does not send user questions to an external AI provider. Unsupported questions receive a clear limitation response rather than fabricated facts.

The public NASA-IBM Lunar Foundation Model is linked as a research resource only. It is a geospatial/image model, not the engine behind NOVA.
